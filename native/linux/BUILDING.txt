Verified native build arrangement

Target: original RG DS, stock Linux 1.1, ARM64, Wayland/Weston and the stock
Mali EGL/GLES driver. This is native ARM64 GameMaker YYC output, not Android
emulation. Other handhelds, firmware and x86 game builds need separate checks.

Use GameMaker runtime 2026.100.0.1046 from an authorized installation. The
corresponding IDE is 2026.100.0.1083. The SDK and its licensed YYC runtime are
external prerequisites and are not included in this package.

The verified host used Clang/LLD, CMake, Meson, Ninja, pkg-config, Python 3,
Wayland protocol generation and a Debian 12 ARM64 sysroot with GCC 12 C++
headers/libraries. Keep the cross-build sysroot separate from the host OS.
The original RG DS's system EGL/GLES libraries are used at runtime, not copied
from that sysroot or replaced on the device.

Game code generation
Generate the Linux YYC C++ files and game.unx with the pinned Igor. The compile
invocation used this structure, with local SDK/user/project paths supplied:

  Igor --runtime=YYC --project=<project.yyp> --runtimePath=<runtime> \
    --cache=<build/compiler> --temp=<build/temp> --config=Default \
    --user=<authorized-GameMaker-user-directory> --of=<output/game.unx> \
    --tf=<output/game.zip> -j=4 -- linux Compile

Use the generated Default/Scripts/llvm-linux C++ files with that same SDK's
yyc/include headers. Compile for aarch64-linux-gnu, C++14, -O3, -DYYLLVM and
the ARM64 sysroot. A precompiled pch.hpp and four workers were used. Link those
objects with yyc/linux/libyoyo_yyc-arm64.a from the SDK, the matching GL4ES
libGL.so.1, and curl, crypto, dl, m, pthread, rt, ssl, X11, Xext, Xfixes,
Xrandr, Xxf86vm and z. Do not use the host x86 runner emitted by codegen.
Strip the release executable with llvm-strip --strip-unneeded. Preserve the
unstripped executable privately for debugging. Use -ffile-prefix-map for all
local source/build paths and verify the resulting ELF architecture and RPATH.

Display integration
Obtain the GL4ES revision and archive checksum in display/upstream.json, apply
display/gl4es-wayland.patch with patch -p1, and build Release with DEFAULT_ES=2,
NO_GBM=ON and CMAKE_SKIP_RPATH=ON for ARM64. Link against the ARM64 Wayland
client/EGL libraries. The adapter calls the device's vendor GLES/EGL directly.

Build display/linux-display.c as a shared ARM64 library with -O2 -fPIC
-fvisibility=hidden -shared and -ldl. Its native-api.h is included; EGL/GLES3
headers are required. This exports the GameMaker extension entry points and
uses shared GPU textures for the lower window. It does not copy frames via CPU.

Build unmodified Xwayland 22.1.9 with Meson: glamor=false, glx=false,
xvfb=false, xdmcp=false, xdm-auth-1=false, secure-rpc=false, dri3=false,
drm=false, xselinux=false, xkb_bin_dir=., xkb_dir=/usr/share/X11/xkb,
xkb_output_dir=/tmp and built-in fonts. Bundle xkbcomp next to Xwayland.
The launcher starts it from that directory with local cookie authentication
and TCP disabled. X11 supplies GameMaker input/focus; graphics use Wayland.

Packaging
Put runner, game.unx, matching music/lang/mods and gamecontrollerdb.txt in data.
Dual Screen also needs data/libAM2RThor.so. Put launch.py, focus-game.py and
volume-keys.py in runtime; Xwayland/xkbcomp in runtime/bin, GL4ES in
runtime/graphics and required X11 libraries in runtime/lib. Preserve their
licences. Use edition.json with game_name AM2RStandardLinux or AM2RDualLinux.
Place launch.sh at the folder root and keep its executable bit. Runtime saves
and logs live in state; never include an existing state directory in a release.
The launcher passes an absolute -game path to game.unx. Without that argument,
this runtime looks for assets/game.unx instead of the packaged data layout.

The matching handheld Autopatcher source and payload generator are in
autopatcher/linux in this repository.
Generate each payload from a private canonical game ZIP and the original
AM2R 1.1 ZIP, then require an exact reconstruction of that canonical ZIP.
Compiled games and media remain private. A source rebuild may differ due to
compiler timestamps; exact reconstruction refers to each specific packaged ZIP.

Verification
Run runtime/test_save_location.py with Python. Verify a fresh Ports launch,
clean exit/relaunch, saved settings/progress, controller and volume buttons,
audio, and lower-screen touch on the actual target. Keep game_id 0 for save
compatibility with this Android port. Copy save1..3/data.sav/extras.sav while
both games are closed; do not transfer platform-specific config.ini.

Current release integration
The in-game title is V1.6.2. Linux options metadata is 1.6.2.0 and public release
metadata is 1.6.2. Set edition.json game_label to AM2ARM or AM2ARM DS for
window focus, retaining its original game_name/save identity.

The matching native extension can be built with display/build-display.sh. Set
SYSROOT to a Debian 12 ARM64 development sysroot with GCC 12 startup files and
EGL/GLES headers; install Clang, LLD and llvm-strip on the build host.
