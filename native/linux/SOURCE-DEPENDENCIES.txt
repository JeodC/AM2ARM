The unchanged runtime sources are archived with v1.6.1. See
dependencies/README.txt for both corresponding-source downloads and hashes.
AM2ARM-1.6.1-dependency-sources.zip:
https://github.com/PatchDev-AM2ARM/AM2ARM/releases/tag/v1.6.1

It supplies the corresponding source archives, Debian patches/build rules and

versions and source hashes. Upstream files and notices remain unchanged.
