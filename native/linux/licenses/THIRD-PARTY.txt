Native Linux display support

GL4ES is based on https://github.com/ptitSeb/gl4es at revision
bc4314d8369f169d3fa81c5ed1b46b3dba4e74a5, with local Wayland and dual-output
support. Its MIT notice is in gl4es.txt. Matching integration source is supplied
separately with the Linux release.

Xwayland 22.1.9 is built from the original X.Org source, with software X11
windows for input and a relocatable xkbcomp lookup. Game graphics use native
Wayland and the device's EGL/GLES driver. Its notices are in Xwayland-COPYING.txt.
https://www.x.org/releases/individual/xserver/xwayland-22.1.9.tar.xz

Supporting X11 libraries and xkbcomp come from Debian 12 ARM64 packages.
Their unmodified copyright and licence files are included in this directory.
Package source is available from https://sources.debian.org/ and the Debian
archive. No system graphics driver, GameMaker SDK or compiler is included.
GameMaker's runtime remains subject to its own terms; game code and media
retain their original ownership and conditions.
