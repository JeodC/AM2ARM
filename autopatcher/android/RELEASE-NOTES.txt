AM2ARM Android 1.6.2

The Standard and Dual Screen title screens and the Autopatcher display 1.6.2.
Both Android editions retain the gameplay and controls from 1.6.1.

Updating
Back up your saves, install the 1.6.2 Autopatcher over your existing copy, and
select your original AM2R_11.zip. Choose the edition you use, then install
the generated APK over your existing game to keep its saves. Standard and
Dual Screen have separate packages and save data.

Both game packages use Android version code 1005017. The Autopatcher uses 21.
All three use version name 1.6.2 and the existing release signing identity.

Source
The repository contains the matching media-pruned sources and restoration
instructions. Keep your original AM2R 1.1 ZIP for patching and restoration.
