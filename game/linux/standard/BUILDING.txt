Building AM2ARM 1.6.3 — ARM64 Linux Standard

Restore the matching media with the repository restorer and your original
AM2R 1.1 ZIP as described in README.txt. This is a complete independent Linux
project, with no Android-source overlay step. Open AM2RStandardLinux.yyp; its name
preserves the native engine's save-folder identity. The title is V1.6.3.

Use an authorized GameMaker Beta IDE 2026.100.0.1083/runtime 2026.100.0.1046
installation and the native ARM64 YYC integration in
native/linux in this repository. That directory
contains the launcher/display source, GL4ES changes, notices and exact build
arrangement. GameMaker and the cross-build sysroot are external prerequisites.

For Dual Screen, compile display/linux-display.c from that integration directory
as extensions/AM2RThor/libAM2RThor.so before compiling this project. A matching
native-api.h and build-display.sh are supplied. The generated library is excluded
from this repository. asset-inputs.json records its release hash
under generated_inputs. The restorer reports it separately and never supplies
or overwrites a locally built library. Compiler differences can change its hash.
Both editions also require rumble/build-rumble.sh from the integration directory.
Build its output as extensions/AM2RHaptics/libAM2ARMHaptics.so before compiling.
This generated extension is likewise recorded separately in asset-inputs.json.
Include the built library in the installed game's data folder beside game.unx.
Both editions also require saves/build.py from the integration directory:

  python3 saves/build.py --sysroot /path/to/arm64-sysroot --output /path/to/project/extensions/AM2RSaveTransfer/libAM2ARMSaves.so

Include libAM2ARMSaves.so beside game.unx. The launcher sets AM2ARM_SAVE_DIR
to the portable save directory. Backup/Restore uses this scoped helper while
the GameMaker file sandbox remains enabled.

The pinned Igor generates Linux YYC C++ and game.unx. Cross-compile/link the
C++ for aarch64-linux-gnu with the licensed ARM64 YYC library, then package the
matching launcher and dependencies as described in the integration BUILDING.txt.
Do not substitute the host x86 runner produced during code generation.
Preserve AM2RStandardLinux/AM2RDualLinux, game_id 0 and resource ordering.
Do not include existing state folders or restored media in source distributions.
Tested native targets include RG DS stock Linux and G350/ROCKNIX. See the
release compatibility list; this is not a universal Linux firmware build.
