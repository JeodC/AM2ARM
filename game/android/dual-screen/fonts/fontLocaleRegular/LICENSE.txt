AM2R Locale Compact / AM2R Locale Regular bitmap fonts

These are renamed, subsetted bitmap conversions of Fusion Pixel Font
2026.10.25 (Japanese forms), licensed under SIL Open Font License 1.1.
They do not incorporate glyphs from AM2R's original font resources.

Source project: https://github.com/TakWolf/fusion-pixel-font
Pinned release: https://github.com/TakWolf/fusion-pixel-font/releases/tag/2026.10.25
10px source: fusion-pixel-font-10px-proportional-bdf-v2026.10.25.zip
12px source: fusion-pixel-font-12px-proportional-bdf-v2026.10.25.zip
Source files and SHA-256 provenance are retained with the font generator.
Contributing font source projects:
  Ark Pixel: https://github.com/TakWolf/ark-pixel-font
  BoutiqueBitmap9x9: https://github.com/scott0107000/BoutiqueBitmap9x9
  Cubic 11: https://github.com/ACh-K/Cubic-11
  Galmuri: https://github.com/quiple/galmuri

Changes: subset to the game's selectable language catalogues and case variants;
convert BDF glyphs into PNG/GMFont resources; retain each glyph's original bitmap,
horizontal bearing and advance; add transparent line-box padding. No smoothing,
resampling, synthetic accents or missing-character substitution is performed.
The converted font software remains under OFL-1.1. The following unmodified
notices from the release archives apply to the font and its source contributions.
The application itself does not become subject to OFL by using these fonts.
