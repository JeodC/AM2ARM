Building AM2ARM 1.6.2 — Android Dual Screen

Restore the matching media with the repository restorer and your original
AM2R 1.1 ZIP as described in README.txt. Install GameMaker Beta IDE
2026.100.0.1083 and runtime 2026.100.0.1046 through your authorized installation.
Obtain its Android SDK, NDK and JDK dependencies separately. No GameMaker SDK,
release key or proprietary runtime is included.

Open AM2R-project.yyp and build Android ARM64 with YYC. Use the matching Android
Autopatcher source in autopatcher/android.
Apply prepare_game_metadata.py and prepare_runtime_performance.py to isolated
project/runtime copies before compiling. game-metadata/game.json is authoritative:
Android versionName is 1.6.2 and versionCode is 1005017. Display labels are
AM2ARM and AM2ARM DS; the in-game title is V1.6.2. Preserve com.community.am2r
for Standard and com.community.am2rdual for Dual Screen, numeric game_id 0 and
the existing save format. Read RUNTIME-INTEGRATION.txt for controller handling.

Use your own signing key and a separate package ID for development installs.
An APK signed with a different key cannot replace the official installation.
Keep keys, preferences, restored media and complete game builds private. Building
with different timestamps and signing inputs need not reproduce identical APK
bytes. Patcher verification requires exact reconstruction of its own input APK.
